# Akarsh Sahlot — Portfolio

Personal portfolio built with Next.js and customized for Akarsh Sahlot.

## Quick Start

Install dependencies:

```sh
npm install
```

Run locally:

```sh
npm run dev
```

Then open the URL shown in the terminal (usually `http://localhost:3000`).

## Customize Content

Most content lives in the `utils/` folder:

- `utils/profile.js` — name, links, email, phone
- `utils/outer.js` — hero text
- `utils/mySelf.js` — about + skills
- `utils/works.js` — experience
- `utils/projects.js` — GitHub projects feed config
- `utils/contact.js` — contact section

Main layout is in `pages/index.js`.

## Build

```sh
npm run build
```

## Deploy

Deploy easily on Vercel by importing the GitHub repo.
